## Reproduce the computational findings

[![Reproducibility checks](https://github.com/sunshineluyao/ImpactOfFossilFeulPrice/actions/workflows/reproducibility.yml/badge.svg)](https://github.com/sunshineluyao/ImpactOfFossilFeulPrice/actions/workflows/reproducibility.yml)

This repository separates **original three-stage model notebooks** from independently rerunnable **diagnostic reanalysis**. For a documented first run (Python 3.11):

```bash
python -m pip install -r code/requirements-revision.txt
python -m unittest discover -s code -p 'test_*.py' -v
python code/revision_experiments.py
```

The script writes new results into the tracked `data/revision_cleaned/` and `data/revision_results/` paths; use a clean checkout or temporary branch to compare runs. It does **not** retrain the original LSTM–GPR, inflation ensemble, or AutoGluon models. Scenario-window holdouts do not establish realized out-of-sample predictive accuracy.

**Start here:** [Reproducibility protocol](REPRODUCIBILITY.md) · [Code and exact diagnostics dependencies](code/README.md) · [Data provenance](data/README.md) · [CI checks](.github/workflows/reproducibility.yml).

## Research overview

This repository supports a study of how fossil-fuel price volatility propagates through inflation and the weighted average cost of capital (WACC) for energy-transition projects. The analysis uses a three-stage modeling pipeline: fossil-fuel price forecasting, inflation prediction, and sector- and region-level WACC estimation.

The public artifact is organized to keep the manuscript, presentation materials, code, and data documentation directly connected. The links above open the official paper record and presentation materials; the folders below contain the corresponding computational materials.
